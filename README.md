# OrbitoonZ

OrbitoonZ is a small 2D arcade space shooter built in Unity.

## Features
- Player movement and shooting
- Enemy spawning and basic AI
- Power-ups
- Score and lives system
- WebGL playable build

## Tools
- Unity
- C#
- Git
